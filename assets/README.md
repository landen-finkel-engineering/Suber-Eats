# assets

Finished, game-ready files only. Working files (aseprite, psd) go in `art_source/`.

- `graphics/sprites/characters/` Rico and other characters
- `graphics/sprites/enemies/` UFOs and other enemies
- `graphics/objects/` platforms, the house, anything Rico bounces off or delivers to
- `graphics/backgrounds/` 320x180 backgrounds
- `graphics/ui/` buttons and menus
- `audio/music/` .ogg
- `audio/sfx/` .wav, .ogg or .mp3 (Godot can't play .m4a)

Export pngs at 1x size. Name files lowercase_with_underscores.
